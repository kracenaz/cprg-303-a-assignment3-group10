### Setup Steps

1. Clone the repository https://github.com/kracenaz/cprg-303-a-assignment3-group10.git
2. Open the project folder cprg-303-a-assignment3-group10
3. Run npm install on terminal
4. Create .env file in project folder and add these firebase variables:
   EXPO_PUBLIC_FIREBASE_API_KEY=  
    EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=  
    EXPO_PUBLIC_FIREBASE_PROJECT_ID=  
    EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=  
    EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=  
    EXPO_PUBLIC_FIREBASE_APP_ID=
5. Retrieve firebase configuration from group 10 to add to .env file
6. Start the application (npx expo start --clear) using Expo Go or Android Emulator
